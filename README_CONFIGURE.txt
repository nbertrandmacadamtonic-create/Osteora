OSTÉO PRATIK — PACK SUPABASE CONFIGURÉ

Le fichier supabase-config.js contient déjà :
- la Project URL
- la Publishable key publique

À déposer à la racine du dépôt GitHub :
- backoffice.html
- backoffice.css
- backoffice.js
- backoffice-bridge.js
- responsive-web.css
- supabase-config.js

Votre index.html doit déjà contenir juste avant </body> :
<script src="backoffice-bridge.js"></script>

Ne modifiez pas app.js ni styles.css.

Après déploiement :
1. Ouvrir backoffice.html
2. Se connecter avec l'adresse administrateur Supabase
3. Si la base est vide, cliquer une seule fois sur
   « Initialiser la base depuis Ostéo RA »
4. Ensuite, les modifications sont centralisées pour tous les appareils.
