Ostéo RA — Add-on Back-office V2

1. Garder votre index.html actuel avec :
   <script src="backoffice-bridge.js"></script>
   juste avant </body>.

2. Mettre à la racine GitHub :
   - backoffice.html
   - backoffice.css
   - backoffice.js
   - backoffice-bridge.js

3. Dans l'application :
   Profil > ⚙
   ou Profil > carte "Back-office Ostéo Pratik" > Ouvrir.

Aucune modification de app.js ni styles.css.
